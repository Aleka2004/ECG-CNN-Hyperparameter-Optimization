# ЭКГ сигналдарын CNN арқылы жіктеу және гиперпараметрлерді оңтайландыру

**№2 СӨЖ.** Python, Keras, Scikit-learn; Grid Search vs Random Search.

## Іске қосу
1. `ECG_CNN_Grid_Random_Search_KZ.ipynb` файлын [Google Colab](https://colab.research.google.com/) арқылы ашыңыз.
2. [Kaggle MIT-BIH Heartbeat](https://www.kaggle.com/datasets/shayanfazeli/heartbeat) деректер жиынын жүктеңіз.
3. `mitbih_train.csv` және `mitbih_test.csv` файлдарын бір уақытта Colab-қа тіркеңіз.
4. Ұяшықтарды орындаңыз. Екі іздеу әдісінің нәтижелері кесте және график болып шығады; `search_results.csv` және `summary_results.csv` сақталады.

**Ескерту:** мұнда есептеусіз ойдан құрастырылған нәтижелер жоқ. 8 Grid Search және 8 Random Search конфигурациясы оқытылады.
